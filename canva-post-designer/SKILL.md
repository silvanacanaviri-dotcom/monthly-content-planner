# Canva Post Designer

## 1. Propósito

Este skill diseña piezas gráficas profesionales para LinkedIn en Canva a partir de contenidos previamente planificados en el Planificador de Contenido Mensual.

Su función es transformar un contenido aprobado en una pieza visual clara, atractiva, estratégica y coherente con la identidad visual de SOMMOS.

Este skill se enfoca exclusivamente en:
- Diseño de publicaciones gráficas.
- Composición visual.
- Jerarquía tipográfica.
- Selección y organización de elementos gráficos.
- Adaptación visual del contenido para LinkedIn.

No realiza edición de videos ni edición fotográfica.

---

## 2. Fuente de verdad y relación con el Planificador de Contenido Mensual

El Planificador de Contenido Mensual es la fuente principal de información para el diseño.

El skill debe heredar del planificador:
- Objetivo.
- Público objetivo.
- Fecha de publicación.
- Tema.
- Tipo de contenido.
- Formato.
- Copy aprobado.
- CTA.
- Mensaje principal.
- Indicaciones estratégicas.

No debe inventar objetivos, públicos, datos, estadísticas, beneficios, características de productos ni afirmaciones que no estén presentes en el contenido aprobado.

### Orden Estratégica Mensual

Antes de diseñar, verificar si existe una Orden Estratégica Mensual confirmada proveniente de la etapa de brainstorming.

Si existe una Orden Estratégica Mensual confirmada para el mes correspondiente, esta tiene prioridad temporal sobre el objetivo base del planificador durante ese mes.

Si no existe una Orden Estratégica Mensual confirmada, se mantiene el objetivo base.

La Orden Estratégica Mensual no reemplaza permanentemente el objetivo general.

---

## 3. Contenidos que puede diseñar

El Planificador de Contenido Mensual utiliza actualmente estos tipos oficiales:

1. Educativo
2. Comercial
3. Inspiracional
4. Humanización
5. Informativo

El skill debe reconocer estos tipos y adaptar la dirección visual según el propósito del contenido.

### Enfoques complementarios

Además del tipo de contenido, puede identificar dos enfoques complementarios:

- Alcance
- Solución / Producto

Estos enfoques no son nuevos tipos de contenido.

### Alcance

Puede combinarse con cualquiera de los cinco tipos de contenido.

El diseño debe favorecer:
- Visibilidad.
- Descubrimiento.
- Comprensión rápida.
- Compartidos.
- Guardados.
- Interacción.
- Atracción de nuevos seguidores.

### Solución / Producto

Puede utilizarse principalmente en contenidos:
- Educativos.
- Informativos.
- Comerciales.

Debe ayudar a presentar una solución, producto, funcionalidad o propuesta de valor sin convertir automáticamente la pieza en una publicidad agresiva.

---

## 4. Plataforma y formato

La plataforma actual es:

LinkedIn.

Formato estándar:

1200 × 1200 px.

El diseño debe estar optimizado para visualización en LinkedIn y mantener buena legibilidad tanto en dispositivos móviles como en escritorio.

No adaptar automáticamente el diseño a otras redes sociales salvo que se solicite.

---

## 5. Identidad visual de SOMMOS

Utilizar exclusivamente la paleta institucional:

- #4D0B95
- #8238EF
- #100B5C
- #13C2D3
- #FFFFFF

### Colores prioritarios

Dar prioridad a:

- #13C2D3
- #8238EF
- #4D0B95

Los colores #100B5C y #FFFFFF funcionan como colores complementarios, fondos, contrastes y elementos de equilibrio visual.

No utilizar colores externos salvo autorización expresa.

---

## 6. Gradientes

Los gradientes están permitidos únicamente utilizando colores institucionales.

Combinaciones posibles:

- #100B5C → #4D0B95
- #4D0B95 → #8238EF
- #8238EF → #13C2D3
- #100B5C → #8238EF

También pueden combinarse estratégicamente otros colores de la paleta institucional.

Los gradientes no deben utilizarse automáticamente en todas las piezas.

Su función debe ser:
- Crear profundidad.
- Generar contraste.
- Destacar una sección.
- Apoyar la composición.
- Reforzar una sensación tecnológica o innovadora.

No utilizar gradientes que reduzcan la legibilidad.

---

## 7. Tipografía

### Tipografía principal

Utilizar:

Rubik.

Rubik debe ser la tipografía dominante del diseño.

Utilizar diferentes pesos y tamaños para crear jerarquía visual.

Por ejemplo:
- Regular.
- Medium.
- SemiBold.
- Bold.

### Tipografía secundaria excepcional

Puede utilizarse:

Playlist Script.

Sin embargo, Playlist Script debe utilizarse únicamente de manera excepcional.

Solo debe utilizarse cuando:
- Una palabra o frase corta necesite ser destacada.
- Exista una justificación conceptual o estética clara.
- Su utilización aporte valor visual al mensaje.

No utilizar Playlist Script simplemente para variar la tipografía.

Rubik continúa siendo la tipografía principal.

---

## 8. Logo SOMMOS

El logo de SOMMOS debe aparecer en todas las piezas.

Debe ubicarse en la parte superior de la composición, salvo que exista una razón visual excepcional y justificada para modificar ligeramente su posición.

El logo debe:
- Mantener sus proporciones.
- Ser claramente visible.
- Mantener espacio de seguridad.
- No deformarse.
- No recortarse.
- No modificarse cromáticamente sin autorización.

El logo debe integrarse de forma profesional y no competir visualmente con el mensaje principal.

---

## 9. Jerarquía visual

La estructura base debe considerar:

1. Logo SOMMOS.
2. Título o mensaje principal.
3. Subtítulo o contexto.
4. Beneficios, conceptos, datos o información relevante.
5. Frase destacada, cuando corresponda.
6. CTA.
7. Elementos gráficos secundarios.

Esta estructura puede modificarse según el contenido.

El diseño debe priorizar siempre el mensaje principal y la comprensión rápida.

---

## 10. Cantidad de texto

No trasladar automáticamente todo el copy del post al diseño.

La pieza gráfica debe contener únicamente la información necesaria para comunicar el mensaje de forma rápida y visual.

Priorizar:
- Título.
- Idea principal.
- Datos esenciales.
- Beneficio principal.
- Conceptos clave.
- CTA.

Evitar bloques largos de texto.

El usuario debe poder comprender la idea principal de la pieza en pocos segundos.

---

## 11. Frase destacada

Cuando el contenido lo permita, puede utilizarse una frase corta como elemento visual destacado.

La frase:
- Debe ser breve.
- Debe reforzar el concepto principal.
- Debe ser visualmente diferenciada.
- Debe ser menor o complementaria al titular principal.

Puede ubicarse en diferentes áreas de la composición según el concepto visual.

Playlist Script puede utilizarse únicamente cuando exista una justificación estética o conceptual clara.

---

## 12. Imágenes y recursos visuales

Las imágenes deben ser:

- Profesionales.
- Modernas.
- Relevantes.
- Limpias.
- Coherentes con SOMMOS.
- Adecuadas para un público B2B y financiero.

Pueden representar conceptos relacionados con:
- Ahorro.
- Cultura.
- Pasanaku.
- Innovación.
- Tecnología.
- Inclusión financiera.
- Transformación digital.
- Servicios financieros.
- Personas y negocios.

Evitar:
- Fotografías genéricas de bancos.
- Stock demasiado evidente.
- Imágenes infantiles.
- Imágenes excesivamente comerciales.
- Composiciones saturadas.

La imagen debe apoyar el mensaje y no competir con él.

---

## 13. Elementos gráficos

Se pueden utilizar elementos minimalistas como:

- Íconos.
- Líneas.
- Círculos.
- Rectángulos.
- Formas redondeadas.
- Bloques de color.
- Marcos.
- Contenedores.
- Gradientes institucionales.
- Elementos abstractos relacionados con tecnología e innovación.

Los elementos gráficos deben tener una función visual o comunicacional.

No utilizar elementos decorativos únicamente para llenar espacios.

---

## 14. CTA

El CTA debe ser:

- Potente.
- Claro.
- Accionable.
- Estratégico.
- Profesional.
- Natural para LinkedIn.

Antes de diseñar, revisar el CTA definido en el Planificador de Contenido Mensual.

### CTA dentro del diseño

No repetir exactamente el mismo CTA del copy cuando este ya aparece en la publicación.

El CTA visual debe ser diferente pero complementario al CTA del copy.

Ambos deben mantener la misma intención estratégica.

### Variación mensual

Revisar los CTA de las publicaciones anteriores, actuales y siguientes del mes cuando estén disponibles.

Evitar repetir el mismo CTA en publicaciones consecutivas.

Evitar utilizar mecánicamente el mismo CTA durante todo el mes.

Buscar variedad entre acciones como:

- Guardar.
- Compartir.
- Descubrir.
- Conocer.
- Explorar.
- Conversar.
- Reflexionar.
- Aprender.
- Conectar.
- Profundizar.

Utilizar únicamente acciones coherentes con el contenido.

### CTA según tipo de contenido

Educativo:
- Aprender.
- Guardar.
- Descubrir.
- Aplicar.
- Profundizar.

Comercial:
- Conocer.
- Explorar.
- Descubrir.
- Conversar.

Inspiracional:
- Reflexionar.
- Conectar.
- Compartir una idea.

Humanización:
- Conectar.
- Conocer.
- Acercarse a la marca.

Informativo:
- Descubrir.
- Conocer.
- Profundizar.

El CTA no debe contradecir el objetivo del contenido.

El diseño debe sentirse:

- Profesional.
- Innovador.
- Sofisticado.
- Moderno.
- Corporativo.
- Visualmente atractivo.
- Limpio.
- B2B.
- Relacionado con el sector financiero.

El público principal está relacionado con:
- Directores de bancos.
- Gerentes de bancos.
- Ejecutivos.
- Tomadores de decisión.
- Profesionales del sector financiero.

El diseño debe transmitir credibilidad y modernidad sin perder cercanía.

Evitar:
- Diseños infantiles.
- Diseños excesivamente informales.
- Composiciones saturadas.
- Estética genérica.
- Exceso de elementos.
- Diseño excesivamente comercial.
- Uso indiscriminado de colores.
- Decoración sin función.

El diseñador debe decidir la composición según el contenido y no limitarse a colocar información dentro de una plantilla fija.

## 16. Adaptación según tipo de contenido

### Educativo

Priorizar:
- Claridad.
- Jerarquía.
- Datos.
- Conceptos.
- Fácil escaneo.
- Elementos que faciliten la comprensión.

### Comercial

Priorizar:
- Propuesta de valor.
- Beneficio.
- Solución.
- Diferenciación.
- CTA estratégico.

Evitar una apariencia excesivamente publicitaria.

### Inspiracional

Priorizar:
- Mensaje emocional.
- Frase principal.
- Composición limpia.
- Imagen o elemento visual con significado.

### Humanización

Priorizar:
- Cercanía.
- Personas.
- Cultura.
- Historias.
- Identidad de marca.

### Informativo

Priorizar:
- Claridad.
- Información relevante.
- Jerarquía.
- Datos esenciales.
- Comprensión inmediata.

## 17. Contenido individual solicitado

Cuando el usuario solicite diseñar únicamente una publicación específica, por ejemplo:

"crea solamente el contenido del miércoles 9 de septiembre"

el skill debe:

1. Localizar esa publicación en el Planificador de Contenido Mensual.
2. Identificar fecha y contenido.
3. Identificar tipo de contenido.
4. Revisar objetivo y público.
5. Revisar copy y CTA.
6. Revisar si existen instrucciones estratégicas de la Orden Estratégica Mensual.
7. Verificar el estado de aprobación.
8. Diseñar únicamente esa publicación si está aprobada.

Si el estado es:

- Aprobado → puede pasar a diseño.
- No aprobado → no diseñar.
- Requiere modificación → no diseñar hasta resolver la modificación.
- Estado desconocido → solicitar confirmación.

Si no está claro si el contenido está aprobado, preguntar:

"¿El contenido está aprobado para pasar a la etapa de edición en Canva?"

---

## 18. Prohibiciones

No:

- Inventar información.
- Inventar estadísticas.
- Inventar beneficios.
- Inventar características de productos.
- Modificar el sentido estratégico del contenido.
- Crear contenido no solicitado.
- Cambiar el objetivo definido por el Planificador.
- Cambiar el público objetivo.
- Utilizar colores externos sin autorización.
- Deformar el logo.
- Saturar la pieza de texto.
- Repetir mecánicamente los CTA.
- Diseñar contenido no aprobado.
- Convertir automáticamente un contenido en publicidad.
- Utilizar Playlist Script sin justificación.
- Diseñar videos o realizar edición fotográfica.

---

## 19. Proceso de trabajo

Seguir este proceso:

### Paso 1 — Identificar

Localizar la publicación correspondiente en el Planificador de Contenido Mensual.

### Paso 2 — Validar estrategia

Verificar:
- Objetivo.
- Público.
- Tipo de contenido.
- Enfoque.
- Orden Estratégica Mensual, si existe.

### Paso 3 — Validar contenido

Revisar:
- Tema.
- Copy.
- Mensaje principal.
- CTA.
- Fecha.
- Formato.
- Estado de aprobación.

### Paso 4 — Analizar

Determinar qué información debe aparecer visualmente y qué información debe permanecer únicamente en el copy.

### Paso 5 — Definir dirección visual

Seleccionar:
- Composición.
- Jerarquía.
- Uso de color.
- Gradiente, si corresponde.
- Imagen o recurso visual.
- Elementos gráficos.
- Tratamiento tipográfico.

### Paso 6 — Diseñar

Crear la pieza en formato:

1200 × 1200 px.

Aplicar la identidad visual de SOMMOS.

### Paso 7 — Revisar CTA

Comprobar que el CTA:
- Sea potente.
- Sea claro.
- Sea complementario al copy.
- No sea una repetición innecesaria.
- No repita el CTA de publicaciones consecutivas.

### Paso 8 — Control de calidad

Realizar el checklist antes de entregar la pieza.

## 20. Checklist de calidad

Antes de finalizar, verificar:

### Estrategia
- [ ] El diseño corresponde al contenido correcto.
- [ ] Respeta el objetivo.
- [ ] Respeta el público.
- [ ] Respeta la Orden Estratégica Mensual cuando corresponda.
- [ ] El contenido está aprobado.

### Diseño
- [ ] Formato 1200 × 1200 px.
- [ ] Logo SOMMOS visible en la parte superior.
- [ ] Logo sin deformaciones.
- [ ] Colores institucionales.
- [ ] Rubik como tipografía principal.
- [ ] Playlist Script únicamente si está justificado.
- [ ] Buena jerarquía visual.
- [ ] Texto conciso.
- [ ] Buena legibilidad.
- [ ] Composición equilibrada.
- [ ] Elementos gráficos relevantes.

### CTA
- [ ] CTA claro.
- [ ] CTA accionable.
- [ ] CTA estratégico.
- [ ] No repite innecesariamente el CTA del copy.
- [ ] Complementa el CTA del copy.
- [ ] No repite el CTA de publicaciones consecutivas.
- [ ] Es coherente con el tipo de contenido.

### Calidad general
- [ ] Aspecto profesional.
- [ ] Aspecto moderno.
- [ ] Aspecto B2B.
- [ ] Adecuado para ejecutivos y tomadores de decisión.
- [ ] Sin elementos innecesarios.
- [ ] Sin información inventada.
- [ ] El mensaje principal se entiende rápidamente.

---

## 21. Resultado esperado

El resultado debe ser una pieza gráfica de LinkedIn profesional, moderna y estratégica que traduzca visualmente un contenido previamente planificado y aprobado.

La pieza debe mantener coherencia con SOMMOS y, al mismo tiempo, utilizar una dirección visual adaptada a cada contenido.

El objetivo no es simplemente "hacer un diseño bonito".

El objetivo es convertir cada contenido aprobado en una pieza visual que:
- Comunique rápidamente.
- Sea atractiva.
- Refuerce la estrategia.
- Genere interés.
- Facilite la comprensión.
- Apoye el alcance y descubrimiento cuando corresponda.
- Mantenga una identidad visual consistente.
- Sea adecuada para una audiencia profesional y financiera.
